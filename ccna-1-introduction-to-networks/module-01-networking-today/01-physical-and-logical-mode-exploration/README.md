# Lab 01 — Physical and Logical Mode Exploration

## 🎯 Objective

Explore the Physical and Logical workspace in Cisco Packet Tracer and become familiar with network devices, connections, and basic Cisco IOS configuration.

## 🧪 Activities

- Investigated the Packet Tracer interface
- Explored network devices in Physical Mode
- Explored network topology in Logical Mode
- Connected end devices to switches
- Connected a console cable to a router
- Installed a backup router
- Configured a hostname using Cisco IOS
- Navigated a small enterprise network

## 💻 Commands Used

```text
enable
configure terminal
hostname Edge_Router_Backup
end
```

## 🧠 Key Concepts

- Physical Mode vs Logical Mode
- Routers
- Switches
- Access Points
- Copper cables
- Console connections
- USB management connections
- Cisco IOS CLI
- Hostname configuration
