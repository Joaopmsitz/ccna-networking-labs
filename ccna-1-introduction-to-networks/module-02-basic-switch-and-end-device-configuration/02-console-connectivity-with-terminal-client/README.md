# 02 - Console Connectivity with Terminal Client

## Overview

This Packet Tracer lab explored physical console access to Cisco devices using both serial console and USB console connections.

The activity demonstrated how to establish local management access to Cisco switches and routers through a terminal emulator.

## Objectives

- Access a Cisco switch through the serial console port
- Access a Cisco router through the Mini-USB console port
- Use a terminal emulator to interact with Cisco IOS
- Display device information
- Configure and verify the system clock
- Explore physical device interfaces
